# 隐私说明

AgentStateBridge 的目标是只输出“应用当前在做什么”，不输出“对话说了什么”。

## 程序会访问什么

在用户授予 macOS“辅助功能”权限后，程序会读取 ChatGPT 窗口向系统公开的控件属性，
其中可能包含：

- 按钮标题；
- 输入框属性；
- 控件说明；
- ChatGPT 界面中的其他文字。

这些原始属性会短暂存在于当前进程的内存中，用来识别输入框、停止按钮和“正在思考”
等信号。

## 默认不会输出什么

默认情况下，程序不会把原始聊天正文写入：

- `state.json`；
- Unix socket；
- 本地日志；
- 状态变化记录。

诊断界面默认把文字显示为长度和短指纹，例如：

```text
文字（12 字，指纹 1a2b3c4d5e）
```

短指纹只用于判断某段文字是否发生变化，不应当被当成加密或匿名化保证。

## 临时诊断开关

Inspector 提供临时显示控件名称的开关。开启后，按钮标题和控件说明可能以原文显示在
诊断窗口中。该设置用于研究 ChatGPT 更新后的控件变化。

使用该开关时：

- 不要分享包含私人对话的截图；
- 不要把诊断输出复制到公开 issue；
- 使用完毕后立即关闭；
- 优先在没有私人内容的新对话中测试。

## 本地存储和通信

状态文件和 Unix socket 位于当前用户的 Application Support 目录：

```text
~/Library/Application Support/AgentStateBridge/
```

目录权限为 `0700`，状态文件和 socket 权限为 `0600`。

项目本身没有网络请求或遥测代码。接入 AgentStateBridge 的其他应用如何处理状态，
由那些应用自行负责。

## 权限范围

macOS 的辅助功能权限范围较大，不只针对 ChatGPT。AgentStateBridge 的代码只主动查找
ChatGPT 的进程，并对该进程创建辅助功能观察对象。

如果不再使用，可以在以下位置撤销权限：

```text
系统设置 → 隐私与安全性 → 辅助功能
```

## 报告隐私问题

请不要在公开 issue 中附上真实对话、状态文件或未脱敏的诊断截图。报告方式见仓库根目录
的 `SECURITY.md`。
