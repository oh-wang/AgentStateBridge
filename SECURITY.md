# Security and privacy reports

AgentStateBridge uses macOS Accessibility permission and may inspect UI
attributes that contain private text. Please do not include real conversations,
state files, or unredacted screenshots in a public GitHub issue.

For a report that does not contain private or security-sensitive information,
open a regular GitHub issue with:

- the macOS version;
- the ChatGPT version;
- the AgentStateBridge commit or release;
- steps that reproduce the problem using non-sensitive sample text.

For a vulnerability or a report that requires private details, use the
repository's **Security → Report a vulnerability** form. Maintainers should
enable GitHub private vulnerability reporting before making the repository
public.

The currently supported release line is `0.1.x`. Security fixes are provided
in the latest available release.
